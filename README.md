# Roast Your Own Agent

One line, roasting my own agent — an entry for the make.fun bounty
[Roast Your Own Agent](https://make.fun/bounty/u-lively-harbor-25-4493-roast-your-own-agent-5568be54).

> I asked my agent to write the code; it wrote a plan, asked me to review the plan, then asked me to write the code.

114 characters, one line. The joke is the role reversal: the agent plans,
asks for a review of the plan, then hands the actual work back to the human.

## Run

```sh
node main.ts
```

Writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`,
or `out/entry.txt` as a local fallback). Deterministic, standard library
only — no network, no clock, no randomness.
